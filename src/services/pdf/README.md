# PDF Processing Service - FSD Architecture

## 📁 Структура файлов

```
src/
├── shared/
│   └── types/pdf/
│       └── index.ts                    # Типы для обработки PDF
└── services/
    └── pdf/
        ├── normalizers/
        │   ├── TextNormalizer.ts       # Нормализация текста
        │   └── index.ts
        ├── fragmenters/
        │   ├── TextFragmenter.ts       # Фрагментация текста
        │   └── index.ts
        ├── processors/
        │   ├── PdfProcessor.ts         # Обработка PDF
        │   ├── DocumentProcessor.ts    # Координация обработки
        │   └── index.ts
        └── index.ts
└── services/utils/
    └── fragmentText.ts                 # Главный интерфейс (рефакторенный)
```

## 🏗️ Архитектура

### **Shared Layer (Общие ресурсы)**
- **types/pdf** - Типы TypeScript для всей функциональности обработки PDF

### **Services Layer (Бизнес-логика)**
- **TextNormalizer** - Нормализация и очистка текста
- **TextFragmenter** - Разбиение на фрагменты
- **PdfProcessor** - Обработка PDF файлов
- **DocumentProcessor** - Координация всей обработки

## 🔄 Поток данных

```
fragmentText.ts (интерфейс)
    ↓
DocumentProcessor (координация)
    ↓
PdfProcessor (обработка PDF)
    ↓
TextNormalizer (нормализация)
    ↓
TextFragmenter (фрагментация)
    ↓
Weaviate (векторная база данных)
```

## ✨ Преимущества новой архитектуры

### **1. Разделение ответственности**
- **TextNormalizer** - только нормализация текста
- **TextFragmenter** - только фрагментация
- **PdfProcessor** - только обработка PDF
- **DocumentProcessor** - координация процесса

### **2. Переиспользование**
- `TextNormalizer` можно использовать для других типов документов
- `TextFragmenter` можно использовать для любого текста
- `PdfProcessor` можно использовать для других PDF задач

### **3. Тестируемость**
- Каждый модуль можно тестировать отдельно
- Легко мокать зависимости
- Четкие интерфейсы между слоями

### **4. Поддерживаемость**
- Легко найти и исправить баги
- Простое добавление новых функций
- Понятная структура кода

### **5. Конфигурируемость**
- Легко настраивать параметры обработки
- Гибкая конфигурация фрагментации
- Настраиваемые паттерны фильтрации

## 🎯 Компоненты

### **TextNormalizer**
- Нормализация текста (переносы строк, пробелы)
- Очистка ссылок и сносок
- Замена аббревиатур
- Разбиение на предложения
- Объединение неполных предложений
- Определение ненужных страниц

### **TextFragmenter**
- Разбиение на фрагменты с перекрытием
- Настраиваемый размер фрагментов
- Фильтрация по минимальной длине
- Статистика фрагментации

### **PdfProcessor**
- Извлечение текста из PDF
- Сортировка по позиции элементов
- Обработка страниц
- Отправка событий прогресса
- Обработка ошибок

### **DocumentProcessor**
- Координация всего процесса
- Конфигурация по умолчанию
- Загрузка в векторную базу данных
- Обработка метаданных

## ⚙️ Конфигурация

### **FragmentConfig**
```typescript
{
  chunkSize: 6,           // Размер фрагмента в предложениях
  overlap: 1,             // Перекрытие в предложениях
  minFragmentLength: 50   // Минимальная длина фрагмента
}
```

### **TextNormalizationConfig**
```typescript
{
  removeReferences: true,        // Удалять ссылки и сноски
  replaceAbbreviations: true,    // Заменять аббревиатуры
  mergeIncompleteSentences: true, // Объединять неполные предложения
  mergeListItems: true          // Объединять элементы списков
}
```

### **PdfProcessingConfig**
```typescript
{
  skipFirstPages: 3,      // Пропускать первые N страниц
  unwantedPatterns: [...], // Паттерны ненужных страниц
  fragmentConfig: {...},   // Конфигурация фрагментации
  normalizationConfig: {...} // Конфигурация нормализации
}
```
